The Motus Shortcut

Add it in one tap: Add the Motus Shortcut

Then go to Motus → Connect → Finish under Apple Health. Below is what it does and how it's made, for anyone who wants to check it or build their own; it uses only Apple's own Shortcuts actions, no other app.

What it does

Reads the last days of Steps, Dietary Calories, Active Calories, Weight and Sleep from Apple Health and sends them to your Motus account. Motus → Connect → Finish runs it the first time with your account's address and token, which it keeps in a small file. After that a daily automation runs it by itself.

Make it

Open Shortcuts, tap +, name it exactly Motus. Add these actions in order (search for each name). “→ Set Variable” means: add Set Variable after it, with that name.

1. Remember where to send

  1. If: Shortcut Input has any value.
  2. Inside the If: Save File: save Shortcut Input; turn Ask Where to Save off; Destination Path motus.txt; Overwrite If File Exists on.
  3. After End If: Get File from the Shortcuts folder, path motus.txt.
  4. Split Text: split the file by Custom |.
  5. Get Item from List: First Item → Set Variable Address. Then Get Item from List: Last Item of the split text → Set Variable Token.

2. Read Health (steps first, then the same for the others)

  1. Find Health Samples where Type is Steps and Start Date is in the last 7 days; Group By: Day.
  2. Repeat with Each item in Health Samples.
  3. Inside: Text: Repeat Item → Start Date (tap it, Date Format Custom yyyy-MM-dd), then |, then Repeat Item → Value.
  4. After End Repeat: Combine Text: Repeat Results with New Lines → Set Variable Steps.
  • Dietary Calories → Calories exactly like Steps (7 days, grouped by day; in the Health app it is called Dietary Energy).
  • Active Calories → Active exactly like Steps (in the Health app it is called Active Energy).
  • Weight → Weight last 7 days, no grouping; the Text is Start Date (Custom yyyy-MM-dd HH:mm) | Value | Unit.
  • Sleep Analysis → Sleep last 2 days, no grouping; the Text is Start Date | End Date (both Custom yyyy-MM-dd HH:mm) | Value | Source.

3. Send

  1. Get Contents of URL: URL Address; Method POST; Header Authorization = Bearer Token; Request Body JSON with the Text fields steps, calories, active, weight, sleep set to the variables above.
  2. If Shortcut Input has any value: Replace Text /api/upload with /connect.html?health=done in Address, then Open URLs with the result. (That brings you back to Motus after Finish.)

Try it and share it

  1. In Motus → Connect, sign in and tap Finish under Apple Health. Allow Health (turn every type on), the file and the connection. You land back on Connect with “Apple Health is connected”.
  2. Home should now show today's and the last days' numbers.
  3. To share it with everyone: in Shortcuts, long-press Motus → Share → Copy iCloud Link. The link holds no account details (those live in the file on each phone).
